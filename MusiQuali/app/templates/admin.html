Les étapes pour configurer votre Raspberry :

Pour pouvoir connecter la Raspberry il y a 3 informations nécéssaire qui nécéssite de chercher directement dans la Raspberry :

  • Utilisateur : il faut taper la commande whoami
  • IP : il faut taper la commande ip a et chercher à la ligne
    inet IPSETROUVEICI brd ADRESSERESEAU scope global dynamic noprefixroute wlp4s0
    ou la première valeur avec la commande hostname -I
  • Mot de passe : Il est défini lors de la création du Raspberry
